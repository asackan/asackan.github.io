I built a system where Claude reads Korean posts and generates English translations. A language toggle button at the top switches between Korean and English.

## Why I Built This

Publishing in Korean only limits search traffic to Korean-speaking audiences. Manually translating every post is tedious. Since Claude already understands the context of what I write, it made sense to let it handle translation too.

## Structure

Hugo has native multilingual support. All it takes is placing files with different name suffixes in the same directory.

```
content/posts/
  my-post.md        ← Korean original
  my-post.en.md     ← English translation (generated by Claude)
```

When both files exist, the PaperMod theme automatically renders a language switcher in the header.

## Hugo Multilingual Configuration

Added language settings to `hugo.toml`.

```toml
defaultContentLanguage = 'ko'

[languages]
  [languages.ko]
    languageName = '한국어'
    weight = 1
  [languages.en]
    languageName = 'English'
    weight = 2
    title = 'asackan'
    [languages.en.params]
      homeInfoParams.Title = 'asackan'
      homeInfoParams.Content = 'A space to record and think'
```

Setting Korean as the default language and registering English as the second. PaperMod renders the language switcher in the header from this configuration alone.

## The `/trans` Command

Created `/trans` as a Claude Code custom command. When invoked, it:

1. Scans for posts that haven't been translated yet
2. Reads the selected `.md` file
3. Claude translates the entire body to English
4. Saves the result as `{slug}.en.md`

Code blocks are left untouched — only the title, tags, and body text are translated.

## Updated `/deploy` Command

Modified the `/deploy` command to automatically check for missing translations before deploying. If any `draft: false` post is missing a `.en.md` file, it raises a warning.

```
⚠️  Public posts missing English translation:
- auto-translate-with-claude
It is recommended to run /trans before deploying.
```

## Workflow

```
1. Write post in Korean
2. /form  → generate frontmatter
3. /trans → generate English translation
4. /deploy → deploy (warns if translation is missing)
```

Translation quality is better than a simple machine translator because Claude understands context. Technical terms and code-related explanations are handled naturally.
